### About me

I'm a CS student in Lahore, Pakistan, learning to solve real business problems with SQL, Power BI, and Excel.
I like data that's a little chaotic — missing values, weird formats, duplicate rows — because untangling it into
something a team can actually make decisions from is the part I enjoy most.

Right now I'm looking for a **remote or hybrid data analyst internship** where I can work on real datasets, real
questions, and real deadlines.

### What I'm currently working on

- Sharpening SQL (window functions, query optimization) and Power BI (DAX) on new datasets every week
- Learning Python for data cleaning & automation (pandas)
- Building one project a month that isn't from a tutorial — picking my own dataset and my own question

**[E-Commerce Sales Dashboard](https://github.com/Raqiqazafar/E-Commerce-Sales-Dashboard)**
Excel dashboard on a Kaggle e-commerce dataset — $4.98B revenue across 582K orders. Found Net Banking and Women's Fashion as the two clearest revenue anchors, and flagged Returned/Canceled orders as a risk worth a category-level deep-dive.
`Excel · Power Query · Pivot Tables`

**[COVID-19 Global Data Exploration](https://github.com/Raqiqazafar/Covid-19-global-data-exploration)**
SQL analysis of global case, death, and vaccination data using CTEs, temp tables, and window functions. Caught a subtle bug in my own query — a `MAX()` grouped by continent was silently answering "worst single country" instead of "continent-wide deaths."
`SQL · CTEs · Window Functions`
