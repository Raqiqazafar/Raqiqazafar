### About me

I'm a CS student in Lahore, Pakistan, learning to solve real business problems with SQL, Power BI, and Excel.
I like data that's a little chaotic — missing values, weird formats, duplicate rows — because untangling it into
something a team can actually make decisions from is the part I enjoy most.

Right now I'm looking for a **remote or hybrid data analyst internship** where I can work on real datasets, real
questions, and real deadlines.

### What I'm currently working on

- Sharpening SQL (window functions, query optimization) and Power BI (DAX) on new datasets every week
- Learning Python for data cleaning & automation (pandas)
- Building one project a month that isn't from a tutorial — picking my own dataset and my own question
